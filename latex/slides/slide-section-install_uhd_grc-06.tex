\begin{frame}{GNU Radio Licensing}
\footnotesize

\begin{itemize}

    \item GNU Radio is released under the GNU General Public License (GPL v3.0 or later).

    \item GPL v3 allows users to:
    \begin{itemize}
        \item Use, study, modify, and redistribute GNU Radio freely.
        \item Develop NI USRP-based SDR applications.
        \item Access and customize the source code.
    \end{itemize}

    \item Software that directly links to GNU Radio libraries must also comply with GPL-compatible licensing.

    \item NI USRPs communicate with GNU Radio through UHD (USRP Hardware Driver), which is LGPL licensed, enabling use in both open-source and commercial applications.

    \item Benefits of GPL v3:
    \begin{itemize}
        \item Promotes transparent and reproducible RF research.
        \item Keeps \texttt{gr-uhd} improvements open and community-driven.
        \item Supports integration with UHD, SoapySDR, VOLK, and other open-source DSP libraries.
    \end{itemize}

\end{itemize}

\end{frame}
