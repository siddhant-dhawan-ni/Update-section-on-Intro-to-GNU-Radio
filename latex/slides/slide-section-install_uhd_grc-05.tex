\begin{frame}{GNU Radio}
\footnotesize

\begin{itemize}
    \item GNU Radio (GR) is an open-source Software Defined Radio (SDR) framework for building real-time signal processing systems.
    
    \item Integrates with NI USRP devices through the UHD (USRP Hardware Driver), enabling software control of RF parameters such as frequency, gain, sampling rate, and bandwidth.
    
    \item Provides a graphical flowgraph-based environment and supports custom signal processing blocks using Python and C++.
    
    \item Enables rapid prototyping of wireless communication systems without requiring dedicated hardware implementations.
    
    \item Common applications include:
    \begin{itemize}
        \item Testing modulation and demodulation schemes
        \item Developing and validating PHY layer algorithms
        \item RF experimentation using NI USRPs
    \end{itemize}
    
    \item GNU Radio combined with NI USRPs provides a flexible, software-centric platform for wireless research, education, and rapid prototyping.
\end{itemize}

\end{frame}
